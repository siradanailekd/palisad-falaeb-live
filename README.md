# ปริศนาฟ้าแลบ LIVE (เล่นหลายมือถือแบบ Kahoot)

## สิ่งที่มีในโปรเจกต์
- พิธีกรสร้างห้องและได้รหัส PIN
- ผู้เล่นเข้าด้วย PIN และชื่อเล่นจากมือถือ/คอมพิวเตอร์
- โหวตคำตอบ 4 ตัวเลือกแบบเรียลไทม์ผ่าน Socket.IO
- แสดงจำนวนโหวตและรายชื่อผู้เล่น
- เสียงข้างมากถูก: ทุกคนขึ้น 1 อันดับ
- เสียงข้างมากผิด: ทุกคนกลับอันดับ 1
- ถ้าเสมอ: พิธีกรเปิดโหวตใหม่
- เป้าหมาย 10 อันดับ

## ทดลองบนคอมพิวเตอร์
ต้องติดตั้ง Node.js ก่อน จากนั้นเปิด Terminal ในโฟลเดอร์นี้ แล้วรัน:

```bash
npm install
npm start
```

เปิด `http://localhost:3000` เพื่อเป็นพิธีกร
ถ้าจะให้มือถือใน Wi-Fi เดียวกันเข้ามาเล่น ให้ใช้ IP ภายในเครือข่ายของคอมพิวเตอร์แทน localhost เช่น `http://192.168.1.20:3000` และอนุญาต firewall ให้พอร์ต 3000

## เปิดเล่นผ่านอินเทอร์เน็ต
นำโฟลเดอร์นี้ไป deploy บนบริการที่รองรับ Node.js และ WebSocket เช่น Render, Railway หรือ VPS แล้วแชร์ URL ให้เพื่อน ทุกคนต้องเข้า URL เดียวกัน

## หมายเหตุ
- เวอร์ชันนี้เป็นต้นแบบเซิร์ฟเวอร์แบบ in-memory: ห้องและสถานะจะหายเมื่อเซิร์ฟเวอร์รีสตาร์ต
- สำหรับใช้งานจริงระยะยาว ควรเพิ่มฐานข้อมูล, ระบบป้องกันการโหวตซ้ำ/เปลี่ยนชื่อ, QR Code, การจัดการห้อง และระบบตั้งเวลา/ปิดโหวตอัตโนมัติ
- ตัวอย่างคำถาม 10 ข้ออยู่ใน `server.js` แก้ไข/เพิ่มได้ในอาร์เรย์ `QUESTIONS`
